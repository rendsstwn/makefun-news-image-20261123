Sum up the world's news of Monday 23 November 2026 in one image. The entry program writes a 1024x1024 PNG digest of 30 stories from that day: NATO holds an emergency session after Russian missiles fall in Poland, the G20 adopts its declaration in Johannesburg, the COP31 backlash grows, Ukraine says it sank a Russian warship off Libya, Iran vows to fight the US blockade, the AI sell-off deepens, the Cikande factory death toll reaches 24, Belgium strikes, Belgrade floods, and 21 more stories from around the world. Sources: Reuters, AP, AFP, Al Jazeera, Just Security, 23 Nov 2026.

## Run it

```sh
python3 main.py
```

This writes `/output/entry.png` (1024x1024 PNG, about 135 KB). The program copies `entry.png` from this repository, with no network, no randomness and no timestamps, so two runs write the same bytes.
